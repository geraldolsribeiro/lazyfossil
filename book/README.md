

## Font

| Element                           | Similar Font        |
| --------------------------------- | ------------------- |
| "LAZYFOSSIL EXCAVATION MAP" title | Cabin Sketch        |
| Handwritten notes                 | Patrick Hand        |
| Sticky notes                      | Balsamiq Sans       |
| Notebook annotations              | Architects Daughter |


Logo has:

* rounded corners
* monospaced feeling
* terminal aesthetic
* soft friendly geometry

So a stronger branding direction would be:


| Purpose              | Font              |
| -------------------- | ----------------- |
| Titles               | Averia Sans Libre |
| Notes                | Patrick Hand      |
| URLs                 | JetBrains Mono    |
| Terminal screenshots | Iosevka           |


## CSS

```css
--lf-title-font: "Averia Sans Libre";

--lf-code-font: "JetBrains Mono";
--lf-ui-font: "Atkinson Hyperlegible";
```
