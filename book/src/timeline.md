# Timeline

The **Timeline** tab shows repository-wide commit history.

It is separate from **File history**, which is based on the selected file.

![Timeline demo](https://pub-0503d20ece60405d98e4a2fa8b21779d.r2.dev/timeline.gif)

## What it shows

- repository commits ordered by time
- commit hash, optional tags, and commit message
- full commit details in the right pane

## How to use it

1. Open a Fossil checkout in lazyfossil.
2. Press `Tab` until you reach **Timeline**.
3. Move with `Up` and `Down`, or click an entry with the mouse.
4. Use `PageUp` and `PageDown` to scroll the details pane.

## Notes

- Timeline is repository-wide history.
- Tags are highlighted in the list.
- The details pane shows the selected commit.
