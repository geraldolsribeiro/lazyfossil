# Working tree

The **Working tree** tab shows all tracked files and extras in the checkout.

It is the main view for file status, previews, and actions.

![working tree demo](https://pub-0503d20ece60405d98e4a2fa8b21779d.r2.dev/working_tree.gif)

## What it shows

- tracked files and their current status
- extra files not yet tracked by Fossil
- missing, deleted, and conflict states
- the currently selected file preview in the right pane

## How to use it

1. Open a Fossil checkout in lazyfossil.
2. Stay on **Working tree** to browse the full file list.
3. Move with `Up` and `Down`, or click a file with the mouse.
4. Use `Tab` to switch to the other views.

## Notes

- This is the default file-browsing view.
- Clean files are shown here too.
- File actions apply to the currently selected file.
