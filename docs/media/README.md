# Media assets

This directory is for screenshots, animated GIFs, and short demo videos used in the README, release notes, and website.

## Suggested workflow
- Record terminal demos with [VHS](https://github.com/charmbracelet/vhs)
- Export screenshots or GIFs from the same scripted terminal sessions
- Keep assets aligned with the current release version

## Conventions
- Store source recordings in `docs/vhs/`
- Store exported images/video in `doc/images/` (or a future `doc/videos/` folder)
- Prefer small, focused demos for individual features
